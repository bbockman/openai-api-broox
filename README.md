# OpenAI API Broox

A full-stack app with a modern chat UI for interacting with the OpenAI API, file/project management for WSL, and temperature controls.

## Structure
- `client/`: React frontend
- `server/`: Node.js/Express backend

## Features
- ChatGPT-like interface
- Temperature control for responses
- File/project management in WSL
- OpenAI API integration
